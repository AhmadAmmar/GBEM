# Certificates, footprints and morphology

Prepares Energy Performance Certificates and building geometry for modelling.

- `certificates.py`, `link.py`, `dwellings.py`, `assemble.py`: certificate cleaning, address linkage, modelling tables.
- `footprints.py`, `lidar_london.py`, `lidar_ni.py`, `get_ni_lidar.py`: footprints and building heights.
- `morphology.py`, `streetscape.py`, `physics.py`: shape, context and envelope descriptors.
- `census_ni.py`, `ber_dublin.py`: supporting area data.

No certificate or address data are stored here; see [DATA.md](../DATA.md) for sources and terms.
